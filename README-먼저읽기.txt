반영 사항
- 상단 프로필·목표 배지 제거, 읽기 버튼 아래 오늘의 독서 진행 영역으로 변경
- 이어 읽기, 읽은 페이지/전체 페이지, 책장 중복 방지
- 가나다순 검색, 취향/목표 설정, 형광펜, 대비 추천

계정 화면과 추천은 시연용입니다. 실제 회원가입·인증·메일 발송·AI API는 없습니다.
계정 입력은 서버로 전송되지 않고 이메일/비밀번호를 저장하지 않습니다.

독서·취향 기록은 해당 브라우저의 로컬 저장소를 사용합니다.
